# THT Customer Survey Final

Bản public cuối để đưa lên GitHub Pages.

## Nội dung đã khóa
- Không có Edit Mode
- Không có PIN
- Không đọc Web_Content khi tải trang
- Logo và hero image nằm local trong `assets/`
- Text VI/EN đã đóng trực tiếp trong `app.js`
- Font: Roboto từ Google Fonts

## Backend
Frontend đang gửi dữ liệu về Apps Script:

https://script.google.com/macros/s/AKfycbycN2gF9D4qOgtxLCf3IfJ-KWRMEEKmC1xMcRswSVwbkijZYqq01Y0QnO6D4pM-k5DS1w/exec

## Đưa lên GitHub Pages
Upload toàn bộ nội dung trong thư mục này vào root repository:

- `index.html`
- `style.css`
- `app.js`
- `assets/logo.jpg`
- `assets/hero.jpg`

Sau đó bật GitHub Pages từ branch chính.

## Test trước khi gửi khách
1. Mở trang và kiểm tra logo/hero xuất hiện ngay.
2. Chuyển VI/EN.
3. Chọn công ty và vai trò.
4. Điền đủ khảo sát.
5. Submit.
6. Kiểm tra Google Sheet: Survey_Response, Survey_Detail, Customer_Feedback, Issue_Log.
